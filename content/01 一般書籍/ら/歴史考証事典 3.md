# 歴史考証事典 3

■ レンジ
専門書、雑学書、一般向け

■ 読みやすさ
読みやすさ:: 3
（江戸時代の制度や風俗を詳細な史料に基づき解説する「事典」形式のため、当時の専門用語や職名、度量衡などの知識が必要とされる箇所が多い [1, 2]。一方で、料理、遊び、広告といった身近なテーマを具体的な逸話と共に平易な筆致で紹介しており、各項目が短く整理されているため、関心のある分野から読み進められる構成となっている [3-5]）

■ 概要
概要:: 本書は、江戸時代の多岐にわたる社会制度、文化、生活実態を豊富な史料から考証した事典の第三集である [6, 7]。大名が江戸城へ登城する際の煩雑な儀礼や、将軍夫妻の食事を支える御台所の知られざる内情、評定所における裁判の厳格な仕組みといった統治機構の裏側を詳述 [1, 3, 8, 9]。また、お茶壺道中や日光例幣使が街道筋にもたらした弊害、貧窮にあえぐ下級武士や御家人の切実な内職事情、金座における貨幣鋳造の工程、そして町人の奇抜な宣伝広告手法や刀・扇子の作法に至るまで、当時の社会の細部を網羅的に解説している [2, 4, 5, 10-14]。時代小説や時代劇の背景を正確に理解するための、写実的かつ学術的な歴史考証の決定版である。

■ 独自の視点・論点
権威的な制度としての歴史だけでなく、下級武士の「食えぬ」実情や金座での厳重な身体検査といった、江戸社会の末端に生きる人々の生々しい実態を「歴史考証」の視点から可視化している点。
